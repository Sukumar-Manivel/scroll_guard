# 🛡️ Scroll Guard

Scroll Guard is a lightweight Chrome extension that detects excessive scrolling behavior and helps users stay focused while browsing.

## 🚀 Features
- Detects continuous scrolling
- Displays warnings when scrolling exceeds limits
- Helps reduce distraction
- Lightweight and fast

## 🧠 How It Works
The extension monitors user scroll activity using JavaScript event listeners.  
When excessive scrolling is detected, a warning is displayed to encourage mindful browsing.

## 🛠️ Technologies Used
- JavaScript
- CSS
- Chrome Extension Manifest V3

## 🔧 Installation

1. Download the repository
2. Open Chrome
3. Go to **chrome://extensions/**
4. Enable **Developer Mode**
5. Click **Load Unpacked**
6. Select the project folder
